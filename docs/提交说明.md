# 智慧灌溉 App 提交说明

## 一、项目简介

面向家庭种植的物联网灌溉 App（Android 原生，Java）。手机端负责配置入口、数据展示和远程管控，
具体的定时调度、阈值判断和 AI 推理都在服务端完成，App 只下发命令、展示回执，避免两端逻辑打架。

## 二、功能清单

| 模块 | 说明 |
|---|---|
| 登录 / 注册 | 账号密码登录，返回 user_token 与已绑定设备列表 |
| 设备绑定 | 输入设备 SN + 6 位配网码完成绑定，支持解绑 |
| 首页仪表盘 | 土壤湿度、光照、水位、泵状态，5 秒轮询；断网时展示最后一次缓存并标注离线 |
| 远程控制 | 开泵 / 关泵 / 紧急停止 / 自动·手动切换，命令回执 2 秒轮询 |
| 参数设置 | 自动灌溉开关、土壤上下限、低水位报警线、上报间隔、单次最长运行时长 |
| 历史曲线 | 原始 / 5 分钟 / 1 小时三档聚合，泵启动时段标注为浇水线 |
| 分区管理 | 多分区增删改 |
| 灌溉计划 | 定时、条件（按湿度）、轮灌三种策略 |
| 传感器标定 | 土壤、光照、水位三点标定 |
| AI 建议 | 服务端返回 AI 建议卡片；模型不可用时降级为本地规则 |
| AI 对话 | 多轮对话，可确认执行设备动作（开泵等），执行结果回写上下文 |
| 报警中心 | 未读角标、按状态筛选、分页 |
| 用水报表 | 累计运行时长、次数、估算用水量 + 每日明细 |
| 在线更新 | 启动自动检查 / 设置页手动检查，App 内直接下载安装新版本 |

## 三、技术实现

- 语言与构建：Java 17 + Gradle 8.13，minSdk 24 / targetSdk 34 / compileSdk 35
- 网络：Retrofit 2.9 + OkHttp 4.11 + Gson，统一封装 `NetworkModule`，GET 失败自动重试一次，
  POST 不重试（避免重复下发控制命令）
- 鉴权：`AuthInterceptor` 统一注入 `Authorization: Bearer <token>`，HTTP 401 或业务码 401 时清除登录态回登录页
- 错误处理：服务端既可能用 HTTP 状态码也可能用业务码返回错误，两种都解析，优先展示服务端中文文案
- 离线策略：每个页面缓存最后一次成功响应，断网时回退展示并加离线横幅，不出现白屏
- 轮询管理：首页 5 秒、命令状态 2 秒，页面 `onPause` 时取消，避免泄漏
- UI：Material Components 3 + ConstraintLayout，折叠标题栏、底部 5 tab 常驻 Fragment（切 tab 不重建）

## 四、运行环境与演示

- 安装：直接安装 `01-安装包/智慧灌溉App-v1.1.apk`（Android 6.0 及以上）
- 演示账号：`demo` / `demo123`
- 无设备或无法联网时，可在登录页点「一键演示账号」查看离线缓存数据
- 后端地址集中配置在 `NetworkModule.BASE_URL`，换域名只改这一处

## 五、构建方式

- Android Studio 直接 Open 项目根目录（Gradle wrapper 已内置，需 JDK 17+）
- 命令行：
  ```
  gradlew.bat assembleDebug      # 调试包
  gradlew.bat assembleRelease    # 发布包
  ```
- 产物路径：`app/build/outputs/apk/release/app-release.apk`

## 六、目录结构

```
app/src/main/java/com/example/smartirrigation/
  model/     接口数据模型（与后端字段一一对应）
  network/   Retrofit 服务定义、统一请求封装、类型适配器
  session/   登录态、device_id、本地缓存
  ui/        页面（Activity / Fragment）与列表适配器
  util/      轮询器、演示数据等
  update/    在线更新（查询版本、下载 APK、调起安装）
app/src/main/res/   布局、图标、主题
tools/publish-release.ps1   发版脚本
```

## 七、版本与更新

- 当前版本 1.1（versionCode 2）
- 更新方式：版本发布在 GitHub Releases，App 查询最新版本号后提示更新，用户可直接在 App 内下载安装
- 发版流程：修改 `app/build.gradle` 的 versionCode / versionName → 提交 → 执行 `tools/publish-release.ps1`

## 八、已知限制

- 必须使用 https 后端（Manifest 已关闭明文流量）
- AI 对话依赖服务端大模型；模型超时或不可用时降级为规则建议
- 在线更新首次安装需手动允许「安装未知应用」权限，授权后自动续装
